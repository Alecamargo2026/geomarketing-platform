ETAPA 7: INTEGRAÇÃO DE DADOS REAIS
================================================================================

1. API de Dados do Mapa
   - GET /api/map/neighborhoods
   - Retorna: neighborhoods, summary
   - Filtros: state, city, zoom, potentialMin
   - Arquivo: src/app/api/map/neighborhoods/route.ts

2. Hook de Dados do Mapa
   - useMapData(options)
   - Retorna: neighborhoods, summary, loading, error
   - Arquivo: src/hooks/useMapData.ts

3. Sincronização em Tempo Real
   - useRealtimeMap(options)
   - Supabase Realtime
   - WebSocket
   - Arquivo: src/hooks/useRealtimeMap.ts

4. Banco de Dados
   - PostGIS para geometrias
   - Tabelas: GeoNeighborhood, CustomerLocation, GeoMetadata, GeoCompetitor
   - Triggers automáticos
   - Arquivo: prisma/migrations/add_postgis_tables.sql
