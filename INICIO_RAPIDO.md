# 🚀 INÍCIO RÁPIDO - GeoMarketing Platform

## ⚡ 3 Passos para Começar

### 1️⃣ Setup Supabase (10 min)
```
1. Acesse https://supabase.com
2. Crie novo projeto
3. Copie as 3 chaves de API
4. Abra SQL Editor
5. Cole o SQL de SETUP_SUPABASE.md
6. Clique em "Run"
```

### 2️⃣ Setup Local (5 min)
```bash
npm install
# Crie .env.local com as chaves do Supabase (ver ENV_SETUP.md)
npm run dev
```

### 3️⃣ Deploy Vercel (5 min)
```bash
git push origin main
# No Vercel: conecte repositório + adicione variáveis + deploy
```

**Total: ~20 minutos até produção** ⚡

## ❓ Dúvidas Frequentes

**P: Preciso de cartão de crédito?**
R: Não. Supabase e Vercel têm planos gratuitos.

**P: Quanto custa?**
R: Gratuito até 100k requisições/mês (Supabase) e 100 deployments/mês (Vercel).

**P: Posso usar meus dados?**
R: Sim! Use a página de importação para adicionar seus clientes.

**P: Como faço backup?**
R: Supabase faz backup automático. Você também pode exportar dados.

**P: Posso compartilhar com minha equipe?**
R: Sim! Compartilhe a URL de produção. Cada pessoa faz seu login.

## 🆘 Problemas?

1. **Erro de build**: Rode `npm run build` localmente
2. **Erro de autenticação**: Verifique `.env.local`
3. **Mapa não carrega**: Verifique console do navegador
4. **Dados não salvam**: Verifique RLS no Supabase
