#### **Especificações Técnicas**

```
VARIANTES (10):
├─ Primary (ação principal)
├─ Secondary (ação alternativa)
├─ Tertiary (ação menos importante)
├─ Danger (ações destrutivas)
├─ Success (confirmação)
├─ Warning (atenção)
├─ Icon (apenas ícone)
├─ FAB (Floating Action Button)
├─ Group (múltiplas ações)
└─ Split (dropdown + ação)

TAMANHOS (3):
├─ SM: 32px (desktop), 32px (mobile)
├─ MD: 40px (desktop), 36px (tablet), 44px (mobile)
└─ LG: 56px (desktop), 44px (mobile)

ÍCONES (60+):
├─ 30 Feather Icons (simples, limpo)
└─ 30 Material Design Icons (mais detalhado)

ESTADOS (8):
├─ Default (normal)
├─ Hover (mouse over)
├─ Active (pressionado)
├─ Focus (teclado)
├─ Disabled (desabilitado)
├─ Loading (carregando)
├─ Success (sucesso)
└─ Error (erro)

CORES (WCAG AA):
├─ Primary: #2563eb (contraste 4.5:1)
├─ Secondary: #64748b (contraste 4.5:1)
├─ Danger: #ef4444 (contraste 4.5:1)
├─ Success: #10b981 (contraste 4.5:1)
└─ Warning: #f59e0b (contraste 4.5:1)

RESPONSIVIDADE:
├─ Desktop (≥1024px): 40px
├─ Tablet (768-1023px): 36px
└─ Mobile (<768px): 44px (mínimo WCAG)

ACESSIBILIDADE:
├─ ARIA labels
├─ Focus visível (outline 2px)
├─ Keyboard navigation (Tab, Enter, Space)
├─ Screen reader otimizado
├─ High contrast mode
└─ Reduced motion support
```

#### **Exemplos de Uso**

```typescript
// Botão Primário
<Button variant="primary" size="md">
  Clique aqui
</Button>

// Botão com Ícone
<Button variant="primary" icon={<SearchIcon />} iconPosition="left">
  Buscar
</Button>

// Botão FAB
<Button variant="fab" icon={<PlusIcon />} tooltip="Adicionar" />

// Botão com Estados
<Button 
  variant="primary" 
  isLoading={loading}
  isSuccess={success}
  isError={error}
>
  {loading ? 'Enviando...' : 'Enviar'}
</Button>

// Grupo de Botões
<div className="flex gap-0">
  <Button variant="group" className="active">Lista</Button>
  <Button variant="group">Grade</Button>
  <Button variant="group">Mapa</Button>
</div>
```
