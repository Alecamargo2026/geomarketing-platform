RESUMO EXECUTIVO
================================================================================

O projeto de Geomarketing Dinâmico é uma plataforma web completa para
inteligência comercial territorial, permitindo importar dados de clientes,
visualizar em mapas interativos, identificar zonas brancas e otimizar
rotas de vendas.

Tecnologia: Next.js 14.2.35 + React 18 + TypeScript + Prisma + PostgreSQL
Deploy: Vercel (https://geomarketing-platform.vercel.app)
Banco de Dados: Supabase PostgreSQL com PostGIS

COMO EXECUTAR O PROJETO
================================================================================

1. Clonar o repositório:
   git clone https://github.com/Alecamargo2026/geomarketing-platform.git
   cd geomarketing-platform

2. Instalar dependências:
   npm install --legacy-peer-deps

3. Configurar variáveis de ambiente:
   cp .env.example .env.local
   # Editar .env.local com suas credenciais

4. Executar o servidor de desenvolvimento:
   npm run dev

5. Abrir no navegador:
   http://localhost:3000

6. Fazer login:
   Email: demo@example.com
   Senha: demo123456
