### ✅ IMPLEMENTAÇÃO FASE 1: ESTRUTURA DE DADOS

#### **Tabelas Criadas (PostGIS)**

1. **`geo_neighborhoods`** (Bairros com Metadados)
   - Demográficos: população, densidade, urbanização, distribuição etária
   - Econômicos: PIB, PIB per capita, renda, poder de compra, desemprego
   - Comercial: estabelecimentos, densidade, índice de saturação
   - Concorrentes: contagem, dados estruturados
   - Infraestrutura: hospitais, escolas, transporte, internet
   - Vendas: clientes, faturamento, cobertura, potencial
   - **Índices**: tenant, geometry, centroid, city, state, coverage, potential

2. **`customer_locations`** (Clientes com Geolocalização)
   - Localização: latitude, longitude, geometry (PostGIS), endereço
   - Dados comerciais: faturamento total/YTD, última compra, frequência
   - Metadados: visitas, dias sem visita, score de prioridade
   - **Índices**: tenant, geometry, neighborhood, customer, priority

3. **`geo_metadata`** (Metadados Estruturados)
   - Entidade: tipo (neighborhood, city, state), ID
   - Metadados: JSON flexível para diferentes tipos
   - Rastreamento: fonte, confidence score, última verificação

4. **`geo_competitors`** (Dados de Concorrentes)
   - Identificação: nome, CNPJ, tipo
   - Localização: latitude, longitude, geometry, endereço
   - Dados: distância, rating, market share

5. **`geo_sync_log`** (Log de Sincronizações)
   - Tipo: IBGE, OpenCNPJ, Base dos Dados
   - Status: pending, running, success, error
   - Métricas: registros processados/atualizados/falhados
   - Timing: início, fim, duração

#### **Funções e Triggers (PostgreSQL)**

1. **`update_neighborhood_centroid()`** - Calcula centroide automaticamente
2. **`update_customer_neighborhood()`** - Atribui bairro baseado em geometry
3. **`recalculate_neighborhood_stats()`** - Recalcula estatísticas de bairro
4. **`trigger_update_neighborhood_stats()`** - Atualiza stats ao inserir/atualizar clientes

#### **View Agregada**

- **`v_neighborhood_summary`** - Dados agregados por bairro para dashboard
  - Inclui: clientes, faturamento, cobertura, concorrentes, metadados

#### **Índices Geoespaciais**

- GIST indexes para geometry e centroid (performance de queries espaciais)
- Índices compostos para queries comuns (tenant + state, entity_type + entity_id)
- Índices para ordenação (coverage, potential, priority_score)
