- Qlik destaca-se em análise associativa
- Mapbox é melhor para customização
- Todos suportam cards expansíveis

### 2️⃣ **Melhores Práticas de UX/UI**

**Cards Dinâmicos:**
- Progressive Disclosure (colapsado → expandido)
- Transições suaves (200-300ms)
- Skeleton loading (shimmer effect)
- Estados de erro com mensagens claras
- Ícones para contexto visual

**Mapas Interativos:**
- Zoom progressivo (Brasil → Estado → Cidade → Bairro)
- Clique em região → detalhes em painel lateral
- Heatmap de cobertura (cores: verde=alta, vermelho=baixa)
- Clustering para 1000+ pontos (Supercluster)
- Popup ao clicar em marcador

**Metadados Estruturados:**
- 6 categorias (Demográficos, Econômicos, Comercial, Concorrentes, Infraestrutura, Vendas)
- JSON flexível para diferentes tipos
- Confidence score (0-1)
- Fonte de dados rastreável
- Última atualização visível

### 3️⃣ **APIs e Fontes de Dados**

**15+ fontes analisadas:**
- IBGE (Gratuito) - População, PIB, densidade
- OpenCNPJ (Gratuito) - Dados de empresas
- Base dos Dados (Gratuito) - Renda, potencial
- GeoAPI Brasil (Gratuito - 1k/mês) - Geocodificação
- ReceitaWS (Gratuito) - CNPJ
- DBDireto (Pago) - Dados de empresas
- OndeAbrir (Pago) - Potencial comercial
- Mapbox (Pago) - Mapas

**Stack recomendado:** IBGE + OpenCNPJ + Base dos Dados + GeoAPI Brasil  
**Custo:** R$ 0-100/mês  
**Setup:** 2-4 horas

### 4️⃣ **Arquitetura em Tempo Real**

**Sincronização:**
- WebSocket (< 100ms latência)
- Supabase Realtime (< 500ms latência)
- Socket.io (< 200ms latência)

**Caching:**
- Redis com GEO commands

- Browser cache (IndexedDB)

**Performance:**
- Supercluster para clustering
- Lazy loading de dados
- Pagination (50-100 itens/página)
