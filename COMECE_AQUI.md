# 🎯 ACESSO RÁPIDO - GeoMarketing Platform

## ⚡ Comece em 3 Passos

### 1️⃣ Abra o Terminal
```bash
cd C:\Users\user\geomarketing-platform
```

### 2️⃣ Instale e Inicie
```bash
npm install
npm run dev
```

### 3️⃣ Acesse no Navegador
```
http://localhost:3000
```

**Pronto! Seu sistema está rodando!** 🚀

## 🔧 Comandos Úteis

```bash

# Build
npm run build            # Build para produção
npm start                # Inicia servidor de produção

# Testes

npm run test:watch       # Testes em modo watch

# Linting
npm run lint             # Verifica código
```
